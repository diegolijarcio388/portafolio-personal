El sitio reúne información sobre mi formación, experiencia profesional, tecnologías y proyectos destacados, con especial foco en desarrollo backend y web.

## 🚀 Contenido

- Presentación profesional.
- Experiencia en CETEMET y CodeArts.
- Tecnologías y herramientas.
- Proyectos destacados.
- Enlaces a GitHub y LinkedIn.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- TypeScript

## 🎨 Diseño

El portfolio utiliza una interfaz oscura y minimalista orientada a mantener una presentación profesional y facilitar la lectura del contenido.

El diseño está adaptado a distintos tamaños de pantalla y utiliza una navegación por secciones dentro de una única página.


## 📚 Contexto

Este portfolio forma parte de mi presentación profesional como desarrollador de software junior.

Actualmente estoy orientando mi perfil principalmente hacia desarrollo backend con Java y Spring Boot, manteniendo también experiencia en desarrollo web y móvil adquirida durante mi formación y prácticas.
